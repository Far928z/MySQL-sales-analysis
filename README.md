# MySQL-sales-analysis
A beginner-level sales data analysis project using MySQL to analyze revenue, profit, products, regions, categories, and monthly sales.

# MySQL Sales Analysis Project
This project analyzes sales data using MySQL. The purpose of the project is to practice SQL skills and generate business insights from sales transactions.

## Objectives

- Calculate total revenue and profit.
- Identify the product with the highest revenue.
- Find the region with the highest profit.
- Identify the category with the highest quantity sold.
- Analyze monthly revenue.
  
  ## Tools Used

- MySQL
- MySQL Workbench
- GitHub
- SQL
  | Column      | Description                                |
| ----------- | ------------------------------------------ |
| Sale_ID     | Unique identification number for each sale |
| Sale_Date   | Date of the transaction                    |
| Product     | Name of the product sold                   |
| Category    | Product category                           |
| Region      | Region where the sale occurred             |
| Quantity    | Number of units sold                       |
| Unit_Price  | Price of one unit                          |
| Total_Sales | Total revenue from the transaction         |
| Profit      | Profit generated from the transaction      |

## SQL Concepts Used

- CREATE TABLE

- SELECT
- SUM()
- GROUP BY
- ORDER BY
- DATE_FORMAT()
- Aggregate functions
- Column aliases
  
  ## Key Findings

- Total revenue was 87,030.
- Total profit was 10,209.
- Laptop was the highest-revenue product.
- Accra generated the highest profit.
- Groceries had the highest quantity sold.
- February 2026 recorded the highest monthly revenue.
  
  ## Limitations

- The dataset contains only 15 sample records.
- The data is illustrative and may not represent real business activity.
- The analysis covers only January to March 2026.
- More records would be needed for stronger business conclusions.
